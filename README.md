# Lab-Agent — учебная лаборатория (этап v0)

Минимальный удалённый shell для понимания того, КАК устроены такие системы.
Философия лабы: прозрачность. Процесс называется lab-agent.exe, виден в диспетчере,
логирует всё в свою консоль, глушится командой `exit`. Ничего не прячем.

## Правила лабы
1. Запуск только на СВОИХ машинах/ВМ.
2. Никакой маскировки: имя честное, персистентность только штатным видимым schtasks.
3. Цель — понять слой ОС: сокеты, процессы, хэндлы, пайпы, протокол.

## Сборка агента (C, чистый WinAPI, ноль зависимостей)
    gcc -O2 -o lab-agent.exe lab-agent.c -lws2_32

## Запуск
Терминал 1 (оператор):
    python listener.py          # слушает 127.0.0.1:4444
Терминал 2 (хост-машина):
    ./lab-agent.exe 127.0.0.1 4444
Команды набираешь в терминале 1. Выход: набери `exit`.

## Автотест (без ручного ввода)
    python test_e2e.py
Поднимает сервер, запускает агента, прогоняет команды, печатает транскрипт.

## Архитектура v0
    [listener.py / nc]  <--TCP plaintext-->  [lab-agent.exe]
                                                 └─ CreateProcessW("cmd.exe /c ...")
                                                     stdout/stderr -> общий пайп -> сокет

## Roadmap (каждый этап = один урок слоя ОС)
- v1: length-prefix фрейминг (почему построчный протокол ломается на бинарном выводе),
      heartbeat, reconnect с exponential backoff + jitter
- v2: TLS через Schannel + пининг сертификата
- v3: запуск от SYSTEM штатной механикой: `schtasks /ru SYSTEM` на своей машине
- v4: стрим экрана GDI BitBlt своими руками (те же вызовы, что в любом VNC)
- Уроки обороны: Procmon/Sysmon смотрят НАШего агента в реальном времени —
  видно каждый CreateProcess/handle/сокет. Это и есть настоящий уровень понимания.

## Известные ограничения v0 (осознанно, исправятся в v1)
- Построчный протокол: бинарный вывод команды理论上 может содержать sentinel.
- Если команда порождает отсоединяющегося ребёнка (`start ...`) — канал держится,
  пока внук жив (лечится Job Object в v1).
- Вывод cmd идёт в CP866, listener пробует cp866/utf-8 автоматически.
